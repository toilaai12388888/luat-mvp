# Luật Lẹ — Web App Ôn Thi Luật

Web app ôn thi Luật tinh gọn dành cho sinh viên Luật với 3 tính năng cốt lõi:
- **Đề cương tóm tắt**: Trọng tâm và các điều luật hay ra đề thi.
- **Trắc nghiệm**: Câu hỏi 4 lựa chọn có giải thích chi tiết và dẫn chiếu điều luật chính thức.
- **Nhận định đúng / sai**: Rèn luyện tư duy pháp lý với căn cứ pháp luật rõ ràng.

## Công nghệ
- **Framework**: Next.js 16 (App Router), React 19, TypeScript strict
- **Styling**: Tailwind CSS v4, Vanilla CSS variables
- **Phông chữ**: Be Vietnam Pro & Lora (Google Fonts)
- **Kiểm định nội dung**: Zod schema validation
- **Đo lường**: Vercel Web Analytics

## Cài đặt và chạy trên máy

1. Cài đặt các gói phụ thuộc:
```bash
npm install
```

2. Chạy máy chủ phát triển:
```bash
npm run dev
```
Mở trình duyệt tại [http://localhost:3000](http://localhost:3000).

3. Kiểm tra mã nguồn và nội dung:
```bash
npm run check
```
